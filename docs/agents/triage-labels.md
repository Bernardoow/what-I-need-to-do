# Etiquetas de triagem

Use o nome de cada papel como seu valor em `Status:`.

- `needs-triage` — aguarda avaliação.
- `needs-info` — aguarda informações.
- `ready-for-agent` — está pronto para um agente executar.
- `ready-for-human` — requer ação humana.
- `wontfix` — foi encerrado sem implementação.
