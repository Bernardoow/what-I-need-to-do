# Escolher a lista por destino nomeado

O CLI começa com o Notion e poderá usar XML posteriormente. Cada destino nomeado aponta para uma lista, como a base do Notion de um projeto ou a de outro projeto. A escolha feita com `win-td use` vale até que outro destino seja escolhido ou que seu cadastro seja removido, e as tarefas continuam onde foram gravadas.

`win-td destination add` cadastra a fonte e o mapeamento de colunas do destino. `win-td destination refresh` relê as colunas da base cadastrada quando sua estrutura muda.
