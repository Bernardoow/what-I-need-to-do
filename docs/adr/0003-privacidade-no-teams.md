# Adiar a janela privada até depois do CLI

O CLI é a primeira interface para capturar e revisar tarefas. Uma futura janela para uso durante reuniões deverá ficar fora da transmissão ao vivo e da gravação do Teams, inclusive quando a tela inteira estiver sendo compartilhada. A escolha da tecnologia da janela dependerá de verificar esse comportamento no Teams.
